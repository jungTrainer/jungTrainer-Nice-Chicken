# REC-04 수익 기록 복구

2026-10-12. 서빙·두 팁·배달·온라인·오프라인 수령의 현금/매출/메뉴/기여도는 공통 `recordIncome`을 사용한다. 가격은 해금 메뉴·확장 45%·메뉴 연구 50%·지점 레벨 10%·지역·일반 수익 효과를 적용한다. 비법 소스의 설정 효과 6%/레벨을 한 번만 적용하며 채널별 효과와 기존 버프는 유지한다.

새 오프라인 추정은 메뉴별 금액을 확정해 저장한다. 과거 미수령 금액은 다시 계산하지 않고 미분류 수익으로 수령하며 과거 판매량을 만들지 않는다. `offlineCount`는 온라인 미션에 포함하지 않는다. 누락된 과거 매출·기여도를 소급 추가하지 않는다. 구매 버튼은 지역별 실제 비용을 공유한다.

새 경제 검사 10개(서빙·팁 6개, 채널·오프라인·가격·과거 저장 4개). 구체적인 통합 결과는 최종 보고서에 기록한다.
