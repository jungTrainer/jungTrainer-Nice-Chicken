# IMP-06: 작은 화면·모달·입력 사용성

완료일: 2026-10-12 (한국 시간).

## 결과와 변경 방법

먼저 가로 화면의 설정 창 넘침, 닫힌 패널의 키보드 접근, Escape 닫기·포커스 복귀 문제를 새 Chromium 검사 3개로 재현했다. 수정 후 같은 검사와 전체 회귀 검사를 통과시켰다.

- `dvh`와 VisualViewport에 맞춰 화면 높이·키보드로 줄어든 영역을 갱신한다. 안전 영역을 상하좌우 여백에 반영하고 하단 탭 높이를 패널 경계와 공유한다. 작은 세로 화면은 메뉴·탭을 유지하며 가로 화면은 게임과 메뉴를 두 열로 배치한다.
- 패널은 하단 탭 위까지 사용하고 목록을 내부 스크롤한다. 모달은 화면 경계 안에서 스크롤하며 상단 닫기 버튼을 고정한다. 설정의 백업 필드·연구·미션·보고서·인증서와 지역 목록도 접근 가능하게 했다.
- `ui.js`가 최상위 화면의 입력을 관리한다. 닫힌 패널·뒤의 모달·배경은 `inert`로 키보드/포인터 접근을 막고, 합성 클릭·Canvas 입력도 앞선 capture 단계에서 차단한다. 활성 패널에서는 하단 탭 전환을 허용한다.
- 모달을 열 때 입력/닫기 컨트롤로 포커스를 이동한다. Tab 순환, Escape 닫기, 닫은 후 부모 모달/열기 버튼으로 포커스 복귀를 지원한다. PIN 취소는 기존 Promise를 해제하고 쿠폰을 사용하지 않는다.
- 미수령 보상은 상단 닫기·배경 클릭·Escape로 보류할 수 있고 설정의 '미수령 수익 보기'로 다시 연다. 닫기는 지급·대기 금액 삭제·메뉴 통계 갱신을 하지 않는다. 재접속하면 미수령 안내가 다시 표시되고 성공적으로 수령했을 때만 정산한다.
- 엔딩 이미지는 `contain`으로 전체를 표시하고 가로 화면에서 이미지와 대사를 나란히 배치한다. 대사 대비·줄바꿈을 보완하고 Enter/Space 진행을 지원한다. 닫기·Escape는 재생만 취소하며 미완료 보상을 지급하지 않는다. 재생 접근 권한은 유지한다.
- 터치 대상은 최소 44px로 보완했다. 텍스트 입력·백업 텍스트 선택과 브라우저 확대를 허용한다. 지역 선택은 가로 스크롤과 키보드 입력을 지원한다.

REC-04 정산·REC-05 엔딩 규칙은 변경하지 않았다. 비동기 PIN 처리 후 쿠폰 감소의 저장 dirty 표시가 빠진 기존 경로는 명시적으로 보완하고 재접속 검사를 추가했다.

## 검증

`npm run check` 통과: main.js, core JS 9개와 service worker, 총 11개 문법 검사.

`npm test` 통과: 새 브라우저 검사 **58개**, 실패·건너뜀 0개. 분류는 오프라인 6개·미션 7개·연구 6개·경제 10개·엔딩 7개·UI 22개다. 이전 유실된 96개 검사의 동일 파일을 실행한 결과가 아니다. `git diff --check`도 통과했다.

| 화면 | 검증한 실제 입력 |
| --- | --- |
| 320×568 | 4개 패널 탭·목록 끝 스크롤·닫기·설정/보고서/지도·엔딩 |
| 390×844 | 같은 경로와 터치 구매·Canvas 손님 선택·서빙·미수령 수령·재접속 |
| 844×390 | 게임/메뉴 분할 배치, 모달 경계·닫기·엔딩 이미지/대사 진행 |
| 1280×900 | 가운데 게임 화면, 모든 패널/모달·엔딩·포커스 동작 |

추가 검사: 중첩 설정→쿠폰→PIN의 포커스 복귀, Tab 순환, 배경 초기화·Canvas·메뉴 합성 입력 차단, 미수령 보류 후 재접속/수령, 올바른 PIN 소비 저장, 390×340으로 축소한 VisualViewport 대응, 지역 가로 스크롤·키보드 선택. 패널 전환과 뷰포트 resize가 끝난 실제 경계를 polling하여 검사했다.

실제 rAF 실행·이미지 로드·저장 실패·백업/가져오기·지점 이동도 함께 회귀 검증했다. 서버·브라우저는 검사 종료 시 정리한다. Android/iOS 실기기, OS 화면 키보드·노치, 스크린리더, 실제 음악 청취는 미실시다. 안전 영역과 VisualViewport 처리는 구현하고 브라우저 resize로 확인했지만 실기기 확인을 대체하지 않는다.

## 남은 문제

- 직원 고용 최대 6명과 화면/자동 서빙 직원 선택 5명, 공용 직원 통계와 지점 기여도의 범위는 IMP-07이다. 복구 과정에서 직원 수 규칙을 새로 정하지 않았다.
- 온라인·직원·배달의 지점 전환 타이머 규칙과 공유 성장 범위를 명시해야 한다. REC-03은 배달 데이터 교체 시 캐시를 비우지만 전체 타이머 정책은 IMP-07/08이다.
- 클래식 전역 함수 설치 순서·main.js의 이전 정의·저장 감시 래퍼·반복 DOM 작업은 IMP-08이다. 이번 입력 차단은 UI 소유권을 관리하며 비즈니스 API 호출을 잠그지는 않는다.
- 매우 큰 금액의 정밀도, 자동 주문만 발생할 때 레벨 확인 지연, 현실적으로 도달하기 어려운 엔딩 목표와 성장 밸런스는 IMP-10이다. 과거 누락 매출은 원본 거래 내역이 없어 복구하지 않았다.
- 실기기 키보드/안전 영역/확대·스크린리더와 실제 혜택 사용의 서버 검증·여러 탭 충돌은 추가 검증/운영 정책이 필요하다.
