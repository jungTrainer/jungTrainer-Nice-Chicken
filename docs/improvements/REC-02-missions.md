# REC-02 미션 복구

2026-10-12. 주간 8종, 일반·직원 구매 카운터, 달성 상태 유지와 최대 성장 후 반복 서빙 목표를 재구현했다. 일간 지급 플래그와 쿠폰을 보존하고, 일간/인증서 지급의 저장 실패는 복구한다. 새 날짜·주간의 정확한 경계에서 진행을 초기화하되 보유 쿠폰은 유지한다.

새 미션 검사 5개와 REC-01 검사 5개를 실행한다. 과거 검사 96개의 동일 파일 복원은 아니다. 구버전 완료 플래그·누적 진행은 해당 기간 동안 유지한다. 현재까지 검사 결과와 이후 통합 결과는 최종 복구 보고서에 기록한다.
