# 오프라인 게임과 매장 혜택 방향

2026-10-15, IMP-18 확정 정책. 매장 운영자의 발급·사용 정책 승인과 main/Pages 출시 승인을 반영하며 종전 미적용 발급 검토안을 대체한다. 상세 수치와 이행 근거는 [미션·서비스 정책](missions-service-policy.md), 실제 조정값은 `COUPON_POLICY`가 원본이다.

## 제품과 목표

매장에서 짧게 즐기는 반복 플레이, 집에서 이어가는 지점 성장, 지역 이야기와 가족 엔딩을 한 앱에서 제공한다. 신규 기본 모드는 기존 운영이며 이지/노말은 명시적으로 선택한다. 성장 업적·게임 방문 도전·미션과 실물 쿠폰은 화면과 지급 경로를 구분한다.

실물 혜택은 **꾸준한 플레이 고객 기준 음료 월 한 장**과 웰컴 쿠폰의 내일부터 사용 가능한 잠금으로 첫 고객의 재방문을 유도한다. 같은 기기의 스탬프 음료 발급은 한국 달력 월 한 장이며, 웰컴 1장은 월 한도와 별도다. 스탬프 30개를 모아 발급하고 월 한도가 찼으면 다음 달 첫 실행까지 카드가 대기한다. 남는 스탬프는 최대 30개를 이월한다. 기존 쿠폰은 무기한으로 보존하고 새 쿠폰만 음료 30일·무/양배추 14일이다.

일간 올클 +1, 주간 올클 +2, 주 1회 게임머니 구매 +2, 직원 확인 새 방문 하루 1회 +5를 기기 전체로 관리한다. 새 반복 v2 주간의 일간 올클 목표는 5회이며, 진행 중인 7회 목표는 해당 기간 종료까지 유지한다. 주간 올클의 무/양배추 한 장과 인증서 보상은 중복 지급하지 않는다. 기존 5,000만원 직접 음료 교환은 진행 중인 주간 종료 뒤 정확한 자동 추정 수익 기반 스탬프 구매로 대체한다. 과거 지급·현재 기간의 확정 보상은 취소하거나 추측 재지급하지 않는다.

## 직원 제공과 로컬 한계

음료는 테이블의 한 방문에 한 병이며 같은 기기도 하루 한 장만 사용한다. 만료가 가까운 사용 가능 새 쿠폰부터 차감하고 무기한 기존 쿠폰은 그 뒤에 쓴다. 직원에게 보여주기/닫기는 제공 완료가 아니며 직원 확인·공개 로컬 PIN·성공 저장 뒤 로컬 사용 기록을 남긴다. 새 방문을 기록하려면 새 정책 적용 후 직원 PIN 확인이 필요하다.

기기 간 테이블 횟수·잔액을 공유하지 않는다. 공개 PIN은 실수 방지이며 계정/서버 인증·실제 제공 증명이 아니다. 양배추·무의 제공량·추가 제공 횟수는 기존 매장 운영을 따르며 새 제한을 임의로 만들지 않는다. 시계 조작 방지는 구현하지 않고 기기 기록·손상 이후 불확실한 과거 사용은 보장하지 않는다.

현재 새 쿠폰/스탬프/발급·사용 원장은 일반 import나 게임 초기화로 되감지 않는다. 이 경로로 외부 새 혜택을 늘리지 않는다. 최신 저장 자체가 사라진 경우 원본과 백업 후보를 구분해 명시적으로 복구하며 과거 사용을 추측하지 않는다. 전체 사이트 저장 삭제를 막는 서버 권한은 없다.

## 성장과 후속 범위

IMP-16의 기존/이지/노말·지역 이야기 6곳·가족 목표와 IMP-17의 첫 방문·지도 조건·접근성 안내를 유지한다. 이지 첫 지역 5~10분/전체 1~2시간, 노말 첫 지역 15~25분/전체 5~8시간은 능동 운영 모델의 설계 목표로, 자동 운영·앱 부재·실제 사람 시간과 구분한다. 확정 미수령은 새 모드/가격으로 재평가하지 않는다.

광고·헬은 이번 개발/출시 범위 밖이다. 광고를 이후 검토해도 실물 쿠폰 추가 발급·월/일 한도 해제를 광고 보상으로 연결하지 않는다. 백엔드·계정·서버 쿠폰 개발은 계획에서 제외한다. 추가 매장 정책·광고 운영 변경은 별도 명시적 결정으로 진행한다.
