# UX-3 메인 화면 표시 설계

메뉴판은 해금된 서빙 버튼과 다음 메뉴 1칸만 표시한다. 다음 메뉴는 구매 버튼이 아닌 안내이며, 업그레이드의 기존 `menuUnlockCost`로 비용과 정확한 원 단위 툴팁을 표시한다. 실제 구매·가격·주문 후보·선택·자동 서빙은 기존 경로를 사용한다. 주문 말풍선은 선택된 손님 위에 하나만 표시한다. 다른 손님을 누르면 해당 손님의 주문을 보여준다.

서빙 안내는 캔버스 밖 메뉴판 위에 배치한다. 선택·오답으로 숨기지 않고 기존 성공 서빙 경로의 표시 전용 이벤트로 숨긴다. 자동 서빙도 같은 성공 경로다. 게임 저장과 별개인 `niceChicken_servingGuide_v1=done`만 기록하고, 게임 상태·dirty·본 저장·백업·export/import/reset에는 필드를 추가하지 않는다. 기존 사용자는 이 표시 기록이 없으면 다음 성공 서빙까지 안내를 한 번 본다. 설정의 다시 보기는 현재 화면에서만 안내를 펼치고 기록을 취소하지 않는다. 다른 탭에는 storage 이벤트로 숨김을 반영한다.

표시 저장 거절은 현재 문서 메모리로 처리하고 게임 정산·저장을 중단하지 않는다. 이 표시 설정 삭제·저장 권한 거절·다른 기기에서는 안내가 다시 보일 수 있다. 보상·쿠폰·paid·사용 이력은 읽거나 지급하지 않는다. 안내와 메뉴의 크기가 바뀐 직후 캔버스 크기를 갱신하며, 캔버스 부모를 크기 감시 대상으로 추가해 재귀 알림을 만들지 않는다.

360/390px 전후 캡처와 자동 Chromium의 서빙·자동 서빙·재접속·순수 조회·표시 저장 실패·다중 탭·작은 가로 화면·터치·포커스·Escape 검사 결과는 PR에 연결한다. 실기기·스크린리더는 미확인이다. UX-4는 소유자 실기기 확인 후 별도 PR로 진행한다.
