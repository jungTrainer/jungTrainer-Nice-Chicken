# UX-6 표시·입력 마감

기존 main의 360/390px 세로·640px 가로·높이 320px 화면을 같은 합성 진행으로 비교했다. 작은 설명/가격/탭·브라우저 기본 버튼 글씨를 14px 이상으로 맞추고 입력/백업 텍스트는 16px을 사용한다. 기존 44px 이상의 버튼·입력·접기 영역은 유지한다. 활성 금색+짙은 글씨, 보조 짙은 청록+흰 글씨, 중립 짙은 회색, 위험 짙은 빨강, 비활성 밝은 회색+짙은 글씨로 통일한다. native disabled를 바꾸지 않고 반투명 처리로 글씨가 흐려지지 않게 한다. 지도처럼 app 밖의 모달에도 같은 표시 규칙을 적용한다.

DOM 텍스트의 실제 계산된 글자 크기·터치 영역·단색/알파 합성 배경 대비를 Chromium에서 검사한다. 일반 본문은 4.5:1, 큰 글씨는 3:1을 기준으로 한다. 그라데이션/이미지/조상 opacity가 있는 글씨와 그림·이모지는 이 자동 대비 계산의 대상이 아니며, 전후 화면을 별도 확인한다. 이는 전체 WCAG 준수나 스크린리더 검증을 의미하지 않는다.

엔딩 재생의 기존 버튼 하나를 하단 내비게이션으로 옮겨 메뉴를 가리지 않게 한다. 게임 탭의 data-panel/class와 분리하고, 기존 엔딩 클릭 연결·해금/표시·모달 입력 소유권과 1회 효과를 유지한다. 스크롤 영역에는 헤더 공간을 확보한다. 기존 viewport 처리에서 이미 포커스된 입력란이 가려질 때만 드러내며, 새 타이머·저장·게임 필드를 만들지 않는다.

새 검사는 세로/가로 패널·모달 스크롤/닫기, 실제 터치·Tab/Shift+Tab·Escape/포커스 복귀, 이름/백업/PIN 입력의 viewport 축소, 모션 줄이기, 엔딩 취소와 조회 중 본 저장·백업·dirty·쿠폰/paid 불변을 확인한다. PIN은 취소하고 실제 제공/발급/초기화/import를 실행하지 않는다. OS 화면 키보드는 자동화하지 않았으며 Chromium viewport 축소로 가려짐을 재현했다. 실기기·스크린리더·실제 손님 시범은 미확인이다.

기존 404개 검사는 수정하지 않는다. 새 검사·전후 캡처·최종 SHA CI·merge commit·실제 Pages 결과는 이 단계 PR에 기록한다. 게임·정확한 원 정산·저장 구조·구매/연구·미션/쿠폰·paid·지급/사용 이력은 유지한다. 후속 변경은 소유자 실기기 피드백을 받은 뒤 별도 범위로 정한다.
