# 반복 미션·방문 서비스 정책

IMP-15. 기준 IMP-14 a991396. 서버/계정 없이 동일 기기 저장과 직원의 실제 확인을 사용한다. 구현은 개발 브랜치의 합성 검증이며 매장 운영/배포 승인이 아니다.

## 현재 규칙과 문제

일간/주간은 각각 8종이다. 구매 여지가 없으면 구매·간판·확장이 모두 서빙으로 치환된다. 지정 메뉴는 마지막 해금 메뉴이므로 다른 대표 메뉴만 운영하면 멈춘다. 일간 올클은 무/양배추 쿠폰 1장·주간 스탬프 1개(하루 1번), 주간은 스탬프 7개를 포함한 올클 뒤 인증서/음료 1장이다. 인증서 미리보기는 발급이 아니다. 음료 교환은 정확한 50,000,000원당 1장이다. 지점 미션·공용 쿠폰 정책을 그대로 유지한다.

로컬 사용 로그는 최근 80개이며 테이블/방문·사용 전후 수량이 없다. 공개 PIN 0000은 실수 방지다. 기존 사용/교환은 primary 저장 실패 때 메모리에서 수량이 변해 재접속 결과와 다를 수 있다. 과거 기록은 추측 보정하지 않는다.

## 이번 목표 이행

기존 일간/주간 목록·진행·done·dailyCompletedToday·인증서·쿠폰은 그대로 둔다. 기존 최대 성장의 repair 경로도 유지한다. **다음 일간/주간 시작에서 각각** 반복 v2 목록을 만든다. 당일 도중 강제 교체하지 않고 목록별 policy 표식을 남긴다. 기존 인증서 명시 사용 후 새 주간 시작도 새 기간이다. 후속 실행은 계속 같은 목록/paid 플래그를 쓴다.

반복 v2는 기존 8종 중 구매 3종을 추가 서빙·모든 메뉴 판매·접속 운영 시간으로 바꾼다. 구매/잠긴 메뉴/배달·온라인 채널을 필수로 요구하지 않는다. 지정 메뉴 대신 실제 열린 주문 메뉴 어느 것이든 판매 횟수를 센다. 올클/스탬프/인증서의 발급 수량·기간은 기존 규칙을 유지하며 발급 강화안은 별도로 검토한다. 접속 시간은 작성자 tick만 누적하며 오프라인 시간을 채우지 않는다. 실제 가격/속도/비용·게임머니 교환 단가는 바꾸지 않는다.

성장 업적은 첫 고용·메뉴 해금·연구·확장 등의 달성 여부를 보여주는 별도 목록이다. 기존 실제 성장/엔딩 조건에서 표시하며 확인/재열기로 새 돈/쿠폰을 지급하지 않는다. 기존 이야기 읽음·엔딩 효과와 별개다.

짧은 방문 도전은 **직접 정확 서빙 5회**, 게임 기념 완료 표시만 제공한다. 매장 대기 3~5분의 설계 목표이며 실제 소요는 손님/사용자 입력에 따라 다르다. 명시적으로 다음 도전을 시작할 수 있고 재시작/완료/재열기는 실물 쿠폰을 발급하지 않는다. 지점 이동으로 진행을 합산하지 않는다. 실제 서비스 방문 정보와 게임 도전 재시작을 분리한다.

## 직원 확인 화면과 로컬 기록

직원에게 보여주기에는 기기 쿠폰 잔량·테이블·방문 시작·음료 제공 전/후와 최근 수량 전후를 표시한다. 화면을 보이는 것/닫기/게임 도전 완료는 사용이 아니다. 사용은 직원 제공 확인 안내 → 공개 로컬 PIN → 성공 primary commit 뒤 기록 완료다. 실패는 사용 수량/인증서/방문/로그를 되돌리고 재시도 안내한다. 미저장 게임 진행은 유지한다.

음료는 한 테이블의 **한 방문에 한 병**이다. 같은 기기 현재 방문의 재확인은 막되, 다른 기기와 테이블 횟수를 공유하지 않는다. 직원은 실제 테이블 제공을 확인해야 한다. 새 방문은 다음 손님/식사임을 명시적으로 확인하며 이전 기록을 삭제하지 않는다. 테이블 번호는 인증/개인 식별 정보가 아니다. 양배추·무는 기존 통합 veg 쿠폰을 유지하며 각각의 새 발급/추가 제공 한도를 임의 적용하지 않는다. 기존 테이블 없는 로그는 기존 기록으로 표시한다. 로그 정리는 방문의 음료 제공 플래그를 초기화하지 않는다.

## 실제 적용 전 검토할 운영안 — 미적용

| 항목 | 구체적 검토안 | 현재 구현 |
| --- | --- | --- |
| 짧은 방문 발급 | 정확 서빙 5회 완료 후 기기당 하루 veg 1장, 주간 방문 3일 뒤 drink 1장 | 게임 완료 표시만, 실물 미발급 |
| 발급 중복 | 신규 방문 발급을 기존 일간/주간과 같은 기간 한도로 합쳐 veg 하루 1장·drink 주 1장 | 기존 규칙 유지, 신규 한도 미적용 |
| 게임머니 교환 | 새 발급 정책 승인 시 미래 교환 중단; 기존 쿠폰/확정 상태 보존 | 5,000만원 교환 유지 |
| 양배추·무 | 통합 쿠폰 1장당 기존 매장 1회분; 같은 식사 추가 제공은 직원 판단, 앱 횟수 제한 미설정 | 기존 통합 수량 유지 |
| 음료 사용 | 직원이 테이블 방문당 1병 확인, 다른 기기 합계는 수동 관리 | 로컬 방문 표시/중복 경고, 서버 인증 없음 |

위 양/횟수/발급 통합 정책은 사용자의 매장 검토 전 운영 기본값으로 활성화하지 않는다. 공개 PIN/로컬 상태 편집·기기 교체·이전 수동 백업은 실제 사용 여부의 완전한 증명이 아니다. 오래된 backup의 지급 이력은 합산하지 않는다. 최신 자료를 잃으면 IMP-14 명시적 복구 한계가 그대로 적용된다. 지역 엔딩/난이도/광고는 IMP-16 이후다.
