# 나이스치킨 타이쿤 수동 테스트 체크리스트

작성일: 2026-05-15

## 1. 기본 실행

- [ ] GitHub Pages URL 또는 로컬 서버 URL로 접속된다.
- [ ] 스플래시 화면이 1~3초 내 사라진다.
- [ ] 콘솔에 치명적인 JavaScript 오류가 반복 출력되지 않는다.
- [ ] 모바일 화면에서 상단 헤더, 캔버스, 메뉴판, 하단 탭이 정상 배치된다.

로컬 실행 예시:

```bash
python3 -m http.server 8000
```

접속:

```text
http://localhost:8000
```

## 2. 기본 서빙 루프

- [ ] 손님이 생성된다.
- [ ] 손님을 터치하면 선택 상태가 된다.
- [ ] 선택 손님의 주문 메뉴를 확인할 수 있다.
- [ ] 맞는 메뉴를 누르면 돈이 증가한다.
- [ ] 맞는 메뉴를 누르면 손님이 정상 처리된다.
- [ ] 틀린 메뉴를 누르면 오류 토스트가 표시된다.
- [ ] 틀린 메뉴를 누르면 평점 또는 인내심 패널티가 반영된다.

## 3. 저장/불러오기

- [ ] 돈, 평점, 레벨, 업그레이드 정보가 저장된다.
- [ ] 새로고침 후 기존 데이터가 복원된다.
- [ ] 설정 > 강제 저장 버튼이 동작한다.
- [ ] 설정 > 초기화 버튼으로 LocalStorage 데이터가 삭제된다.

## 4. 업그레이드

- [ ] 업그레이드 패널이 열린다.
- [ ] 메뉴 해금 구매 후 메뉴판의 잠금 메뉴가 열린다.
- [ ] 간판/인테리어/가게 확장 구매 후 돈이 차감된다.
- [ ] 알바 고용 후 직원이 화면 또는 업그레이드 목록에 반영된다.
- [ ] 직원 개별 업그레이드 비용이 `NaN`, `undefined`, `0원`으로 표시되지 않는다.
- [ ] 직원 개별 업그레이드 구매 후 레벨이 증가한다.

## 5. 연구

- [ ] 연구 패널이 열린다.
- [ ] 연구 시작 버튼이 동작한다.
- [ ] 연구 진행 시간이 표시된다.
- [ ] 연구 완료 후 레벨이 증가한다.
- [ ] 연구 효과가 수익/주문/자동서빙 등에 반영된다.

## 6. 미션/쿠폰/인증서

- [ ] 일간 미션 진행도가 갱신된다.
- [ ] 일간 미션 전체 완료 시 무/양배추 쿠폰이 지급된다.
- [ ] 주간 스탬프가 누적된다.
- [ ] 주간 미션 완료 시 인증서 발급 가능 상태가 된다.
- [ ] 인증서 발급 시 음료 쿠폰이 지급된다.
- [ ] 쿠폰 사용 시 PIN 입력 모달이 열린다.
- [ ] 올바른 PIN 입력 시 쿠폰이 차감된다.
- [ ] 잘못된 PIN 입력 시 쿠폰이 차감되지 않는다.

## 7. 배달/온라인 주문

- [ ] 라이더 고용 후 배달 수익이 발생한다.
- [ ] 이동수단 업그레이드 후 배달 연출 또는 수익/빈도가 변화한다.
- [ ] 온라인 주문 자동 수익이 발생한다.
- [ ] 배달/온라인 수익이 경영 리포트 기여도에 반영된다.

## 8. 지역 확장

- [ ] 지도/지역 확장 모달이 열린다.
- [ ] 현재 지역이 표시된다.
- [ ] 다음 지역 해금 비용이 표시된다.
- [ ] 비용이 부족하면 해금되지 않는다.
- [ ] 비용이 충분하면 다음 지역이 해금된다.
- [ ] 지역 이동 후 해당 지점의 상태가 분리 관리된다.
- [ ] 새로고침 후 현재 지역과 해금 상태가 유지된다.

## 9. 모바일 UX

- [ ] Android Chrome에서 터치 입력이 정상 동작한다.
- [ ] 하단 탭이 안전 영역에 가려지지 않는다.
- [ ] 패널 닫기 버튼이 정상 동작한다.
- [ ] 모달 바깥 영역 터치로 닫히는 모달은 정상 닫힌다.
- [ ] 긴 목록에서 스크롤이 부드럽게 동작한다.

## 10. 배포 전 확인

- [ ] GitHub Pages에서 HTTPS로 정상 접속된다.
- [ ] 이미지 아이콘 파일이 깨지지 않는다.
- [ ] 첫 접속/재접속 모두 정상 동작한다.
- [ ] 콘솔 오류가 없다.
- [ ] LocalStorage 초기 상태와 기존 저장 상태 모두 테스트했다.
