## 테스트 전 준비

테스트 전 다음을 확인한다.

1. 최신 `main` 기준으로 테스트한다.
2. 브라우저는 Chrome 또는 Edge 최신 버전을 우선 사용한다.
3. DevTools Console을 열어둔다.
4. 가능하면 기존 localStorage를 백업하거나 초기화 후 테스트한다.
5. 테스트 결과는 PASS / FAIL / CHECK / N/A 중 하나로 기록한다.

## GitHub Pages 실행 경로 확인

저장소는 public이고 default branch는 `main`이다. GitHub Pages가 활성화되어 있다면 일반적인 접속 후보는 다음과 같다.

```text
https://jungtrainer.github.io/jungTrainer-Nice-Chicken/
```

단, 이 문서 작성 시점에서 GitHub Pages 활성화 여부를 도구로 직접 확인하지는 못했다. 따라서 아래 절차로 확인한다.

### GitHub Pages 활성화 확인 방법

1. GitHub 저장소로 이동한다.

```text
https://github.com/jungTrainer/jungTrainer-Nice-Chicken
```

2. 상단 또는 우측의 `Settings` 메뉴로 이동한다.
3. 왼쪽 메뉴에서 `Pages`를 클릭한다.
4. `Build and deployment` 항목을 확인한다.
5. `Your site is live at ...` 문구가 있으면 해당 URL을 사용한다.
6. Pages가 꺼져 있으면 `Deploy from a branch`를 선택한다.
7. Branch는 `main`, folder는 `/root` 또는 `/docs` 중 실제 `index.html` 위치에 맞게 선택한다.
8. 이 프로젝트는 루트에 `index.html`이 있으므로 `/root` 배포가 적합하다.

## 로컬 실행 경로

GitHub Pages가 비활성화되어 있거나 반영이 지연되면 로컬 실행으로 테스트한다.

### 방법 A: 브라우저에서 직접 열기

저장소를 내려받은 뒤 `index.html`을 더블클릭한다.

주의:

- 일부 브라우저 기능은 `file://` 경로에서 제한될 수 있다.
- localStorage는 동작하지만, service worker나 일부 리소스 경로는 서버 실행과 다를 수 있다.

### 방법 B: 로컬 서버로 실행 권장

터미널에서 저장소 루트로 이동한 뒤 아래 명령을 실행한다.

```bash
python3 -m http.server 8000
```

브라우저에서 아래 주소로 접속한다.

```text
http://localhost:8000/
```

Windows에서 `python3`가 안 되면 다음을 사용한다.

```bash
python -m http.server 8000
```

## DevTools Console 확인 방법

1. 브라우저에서 게임 페이지를 연다.
2. `F12` 또는 `Ctrl + Shift + I`를 누른다.
3. `Console` 탭을 연다.
4. 빨간색 에러가 있는지 확인한다.
5. 테스트 중 버튼을 클릭할 때마다 새 에러가 생기는지 확인한다.
6. 실패가 있으면 에러 메시지 전체와 발생한 조작을 기록한다.

기록 예시:

```text
항목: 메뉴 서빙 버튼
상태: FAIL
조작: 손님 선택 후 후라이드 버튼 클릭
콘솔 에러: Uncaught TypeError: ...
재현 여부: 3회 중 3회 재현
메모: 메뉴 버튼 클릭 직후 발생
```

## localStorage 확인 방법

1. DevTools를 연다.
2. `Application` 탭으로 이동한다.
3. 왼쪽에서 `Storage > Local Storage`를 연다.
4. 현재 테스트 URL을 선택한다.
5. 저장 키와 값이 생성/변경되는지 확인한다.
6. 저장 후 새로고침했을 때 돈, 레벨, 업그레이드, 연구, 지역 상태가 유지되는지 확인한다.

## 테스트 결과 표기 규칙

| 상태 | 의미 |
|---|---|
| PASS | 정상 동작 확인 |
| FAIL | 오류 또는 기대 결과 불일치 확인 |
| CHECK | 추가 확인 필요 |
| N/A | 현재 조건에서 테스트 불가 |
