## IMP-07 범위와 완료

1. 직원 고용 최대 6명과 화면/자동 서빙 선택의 5명 제한을 일치시킨다.
2. 공용 보유금·쿠폰·엔딩과 지점별 성장·매출·미션·연구의 데이터 범위를 명시한다.
3. 직원 교육·개별 수익과 지점 기여도의 저장 규칙을 정하고 기존 값을 임의로 합산하거나 과거 수익을 생성하지 않는다.
4. 지점 이동에서 온라인·배달·자동 서빙 타이머와 미수령 보상이 다른 지점에 섞이지 않게 한다.
5. REC-01~05와 IMP-06의 저장·보상·정산·입력 규칙을 유지하며 지점 이동·재접속·백업·가져오기를 브라우저로 검증한다.
6. 새 58개 검사와 문법 검사를 유지하고 보고서·IMP-08 프롬프트를 갱신한다.

2026-10-12 완료. [데이터 규칙](data-ownership.md)과 [IMP-07 보고서](improvements/IMP-07-staff-branches.md)에 구현·호환·검증·남은 문제를 정리했다. 기존 저장의 직원 수익을 지점별 값으로 추측 분배하거나 중복 합산하지 않았다.
