# 나이스치킨 (GitHub Pages 배포)

## 배포(가장 쉬운 방법)
1. GitHub에서 새 repo 생성 (예: `nice-chicken`)
2. 이 폴더의 파일들을 repo 루트에 업로드/커밋
3. GitHub repo > Settings > Pages
   - Build and deployment: Deploy from a branch
   - Branch: `main` / `/ (root)` 선택 후 Save
4. 잠시 후 Pages URL이 생성됩니다.

## 모바일 테스트
- Android Chrome에서 Pages URL 접속 → 메뉴(⋮) → '홈 화면에 추가' 또는 '앱 설치'

## 참고
- PWA 설치/서비스워커는 HTTPS에서 정상 동작합니다(GitHub Pages는 HTTPS 제공).
